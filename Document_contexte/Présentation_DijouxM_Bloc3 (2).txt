Notre mission vise à garantir la conformité ISO 25010 tout
en développant une version sécurisée (V1) de notre
système. Nous mettons en place un pipeline CI/CD robuste
pour assurer des déploiements continus et sécurisés,
intégrant des audits de sécurité réguliers pour améliorer
notre infrastructure.

• Architecture technique
• Client Browser / Postman → HTTPS/TLS → API REST Symfony
• Auth : JWT (Lexik JWT Bundle) · ORM : Doctrine · BDD : MySQL
• Logs : Monolog → Grafana Cloud · phpMyAdmin (preprod uniquement)
• Docker Compose : php-fpm · nginx · mysql · phpmyadmin
• Orchestration : Coolify + Linux (preprod & production)
• Expérimentation bac à sable
• Coolify + Docker : VM Linux locale → déploiement automatisé validé ✅
• SonarQube : Docker Compose → scan PHP/Symfony opérationnel ✅
• Grafana Cloud : Monolog + k6 → métriques collectées correctement ✅
• Playwright : Node.js + Chromium → tests E2E sur routes JWT ✅
• Difficultés rencontrées : [config réseau Docker · certificats TLS local · variables Coolify]

Montée en charge &
Observabilité
L'observabilité est essentielle pour assurer une
performance optimale. En surveillant en temps réel les
métriques clés comme la latence, le débit, et la surcharge,
nous pouvons identifier rapidement les goulots
d'étranglement et optimiser les ressources, garantissant
ainsi un service fiable et efficace pour nos utilisateurs.

Ce slide présente une évaluation détaillée des
vulnérabilités de notre système. Nous avons identifié les
failles potentielles et mis en place des mesures
correctives pour les sécuriser. L'analyse comprend des
tests réguliers et un suivi constant pour assurer la
protection maximale de notre plateforme et de nos
utilisateurs.

Stratégies pour résoudre les problèmes de sécurité

Priorité

Vulnérabilité identifiée

Action recommandée

Justification

🔴 CRITIQUE

phpMyAdmin exposé en production

Désactiver en prod · restreindre par IP en preprod

Accès direct BDD sans auth forte

🔴 CRITIQUE

Secrets dans .env non chiffrés

Docker Secrets ou gestionnaire type Vault

Fuite credentials si repo compromis

🟠 HAUTE

Absence de rate limiting

ThrottleBundle Symfony / API Gateway

Protection brute force · DDoS

🟠 HAUTE

TTL token JWT trop long

Réduire TTL + implémenter refresh token

Limite l'impact d'un token JWT volé

🟠 MOYENNE

Headers HTTP sécurité manquants

HSTS · CSP · X-Frame-Options (NelmioCors)

Conformité OWASP Top 10 · anti-XSS

🟠 MOYENNE

Logs insuffisants / non centralisés

Centraliser Monolog → Grafana Cloud

Détection incidents · forensique
