Plan de Remédiation — Sécurité V2
3 actions prioritaires pour renforcer la résilience

R1

Rate Limiting

CRITIQUE

Traefik Middleware

Configuration de middlewares Traefik
(IngressRoute) pour limiter les requêtes par IP
et par route. Protection immédiate contre les
attaques par saturation.

R2

Auto-Scaling HPA
HAUTE

Kubernetes HPA

Déploiement d'un Horizontal Pod Autoscaler
Kubernetes : multiplication automatique des
réplicas Next.js dès que CPU > 80%. Scalabilité
horizontale réactive.

R3

Cache Redis
HAUTE

Redis Cluster (Helm)

Intégration d'un cluster Redis (Helm chart)
pour mettre en cache les réponses API
catalogue. Réduit drastiquement la charge sur
PostgreSQL lors des pics.

Objectif V2 : 0 timeout à 2 000 users · Latence < 200ms maintenue · Architecture résiliente et scalable.
